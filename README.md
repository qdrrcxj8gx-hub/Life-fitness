# Life Fitness Astana — портфолио-концепт

Адаптивный сайт на чистых HTML, CSS и JavaScript. Сборка и установка зависимостей не нужны. Шрифты и фотографии хранятся в `assets/`.

## Просмотр

Откройте `index.html` в браузере или запустите Live Server в VS Code. Альтернатива:

```sh
python3 -m http.server 4173
```

Адрес: http://localhost:4173

## Возможности

- Адаптивная вёрстка, мобильное меню и навигация по секциям.
- Фильтры направлений с клавиатурным управлением.
- Карточки направлений с подробностями в модальных окнах.
- Галерея с кнопками и переключением стрелками клавиатуры.
- Годовой абонемент, наполнение, гостевые визиты и заморозка.
- Выбор интересующей услуги и подготовленное сообщение в WhatsApp.
- FAQ, телефон, Instagram и ссылка на адрес в 2ГИС.
- Поддержка reduced motion, видимый фокус, нативные доступные диалоги.

Сайт не отправляет заявки автоматически, не принимает оплату и не собирает персональные данные. Кнопка WhatsApp открывает реальный контакт клуба: отправку подтверждает сам посетитель.
